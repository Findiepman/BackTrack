# Backtrack logo options

1. **01-ring-rewind** (symbol only, app icon): minimal geometric. A buffer ring that loops back on itself with a rewind double-chevron inside. Palette: #0e1014, #ffb547, #f4efe6.
2. **02-vhs-rewind** (symbol + wordmark): retro VHS. Rewind chevrons and italic wordmark with cyan/magenta misregistration, scanlines, tape counter "REW 00:30". Palette: #241044, #0a0516, #00e5ff, #ff2e93, #ffffff, #ff2e3d. Wordmark is live text (Impact/Arial Black stack), so it can vary on other machines.
3. **03-esports-shield** (symbol only): bold gaming badge. Chunky angular B on a shield with an offset hard shadow and a small rewind mark. Palette: #ff2e4d, #0b0b12, #f5ff3b.
4. **04-stopwatch-sticker** (symbol only): hand-drawn organic sticker. Wobbly stopwatch with the last half filled in and a curl-back arrow. Palette: #ffc94a, #1f3a3d, #ff7a59, #fff3d6.
5. **05-swiss-timeline** (symbol + wordmark): Swiss typographic. Black square with a ruler timeline, red playhead and an arrow jumping back, set with a tight Helvetica wordmark. Palette: #111111, #f6f5f1, #ff3b1f. Wordmark is live text (Helvetica/Arial stack).

PNG previews show the large mark plus 128/64/32/16 px renders. `_render/view.html` is the preview wrapper.
